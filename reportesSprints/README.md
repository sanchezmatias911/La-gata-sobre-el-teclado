# Sprint 1 — Planning

## Objetivo del Sprint
Desarrollar la visualización de un calendario semanal y su estructura básica de disponibilidad.

### User Stories:
#### US-9 - Visualización del calendario
#### Criterios de aceptación

1. Se debe permitir al usuario acceder al calendario de disponibilidad desde el sistema.
2. Se deben mostrar las clases disponibles con su fecha y horario.
3. Se debe permitir identificar qué clases tienen disponibilidad y cuáles no.
4. Se debe mostrar información correspondiente a las clases registradas en el sistema.
5. Se debe informar al usuario cuando no existan clases disponibles.
6. Se debe acceder al calendario semanal.
7. Se debe mostrar en el calendario los días de la semana.
8. Se debe permitir que el calendario identifique los días que tienen clases programadas.
